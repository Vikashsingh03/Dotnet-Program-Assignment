# Project 1 — Student Registration

A Web Forms registration page with full input validation. On Register, the submitted name, email and course are displayed on the same page with a success message. No database is used in this project.

## Features

- Student name, email and course fields
- Required-field and email-format validation
- Register shows the details with a success message
- Clear button resets the whole form

## Files

| File | Purpose |
| --- | --- |
| `StudentRegistrationSystem.sln` | Visual Studio solution — double-click to open |
| `StudentRegistration.aspx` + code-behind | Registration form and its C# logic |
| `Web.config` | Application configuration |

## How to Run

1. Open `StudentRegistrationSystem.sln` in Visual Studio 2022.
2. Right-click **StudentRegistration.aspx** and choose **Set as Start Page**.
3. Press **Ctrl + F5**.
